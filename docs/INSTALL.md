# Install a Blockside preview on Android

1. Open the repository's **Actions** tab and select the latest successful **Android preview build** run.
2. In **Artifacts**, download `Blockside-Android-preview` and extract the ZIP.
3. On your Android device, open the APK. If Android asks, allow your browser or file manager to install unknown apps for this installation.
4. Confirm installation, open Blockside, then follow its sign-in and game setup screens. You need a legitimate Minecraft: Java Edition account and internet access to download game files.

Preview APKs are debug-signed and are intended for evaluation. A later preview can require uninstalling the previous preview before Android accepts its different signing key. Uninstalling removes the app's private data; back up worlds first.

Only install APKs from this repository's Actions artifacts or its Releases page.

## Use an offline username

1. Open the account selector in Blockside and choose **Add account**.
2. Choose **Offline username**.
3. Enter a name with 3–16 letters, numbers, or underscores, then tap **Continue offline**.
4. Select a Minecraft version already installed on the device and tap **Play**.

Offline profiles work for local play with installed files. They cannot download Minecraft, verify account ownership, or sign in to multiplayer servers.
